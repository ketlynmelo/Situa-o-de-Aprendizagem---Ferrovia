# Situacao-de-Aprendizagem-Ferrovia
# SA-Ferrovia

## Resumo

Nosso sistema é desenvolvido para auxiliar no monitoramento e gerenciamento de informações relacionadas a uma ferrovia. A aplicação permite acompanhar dados dos trens e sensores instalados ao longo da ferrovia, disponibilizando informações importantes para o controle e acompanhamento das operações. O sistema é uma atividade de aprendizagem voltada a construção da ferrovia, buscando apresentar de maneira simples, organizada e intuitiva.

## Proposta  

A principal proposta do projeto é centralizar as informações relacionadas aos trens, sensores para acompanhar as operações ferroviárias, e permite que diferentes usuários tenham acesso ás informações de acordo com o nível de permissão. O sistema possibilita o cadastro e gerenciamento de trens e sensores, além do monitoramento dos dados coletados. Entre as informações que podem ser acompanhadas estão velocidade, localização, temperatura e possíveis situações de falha.
A aplicação também conta com diferentes níveis de acesso. O administrador possui maior controle sobre o sistema, podendo realizar cadastros, gerenciar usuários e acessar relatórios. Já o usuário comum possui acesso principalmente às funcionalidades de visualização e monitoramento.Além disso, o desenvolvimento busca aplicar boas práticas de organização de software e utiliza conceitos de metodologias ágeis, como **Scrum**, para auxiliar na organização e acompanhamento das atividades da equipe.


## O Sistema conterá:

* Login de usuários
* Cadastro de usuários
* Diferentes níveis de acesso
* Cadastro de trens
* Cadastro de sensores
* Edição de sensores
* Exclusão de sensores
* Associação entre sensores e trens
* Monitoramento dos trens
* Visualização dos dados dos sensores
* Alertas de situações anormais
* Cadastro e gerenciamento de rotas
* Gerenciamento de trilhos
* Geração de relatórios
* Filtragem de informações nos relatórios
* Armazenamento dos dados no banco de dados

As funcionalidades de cadastro, edição e exclusão estão representadas nas páginas presentes na pasta `public`, incluindo `cadastro.html`, `cadastrosensor.html`, `cadastrotrem.html`, `editsensor.html` e `deletesensor.html`.

## Tecnologias Utilizadas

* **HTML** — estrutura das páginas.

## Monitoramento

A área de monitoramento permite acompanhar as informações relacionadas aos trens e sensores da ferrovia.

O objetivo é facilitar a identificação de alterações nos dados coletados e permitir que o usuário acompanhe informações importantes da operação ferroviária de maneira mais rápida e organizada.

O projeto possui uma página específica de monitoramento (`monitoramento.html`) e recursos visuais relacionados à apresentação dos dados.

---
## Controle de Acesso

O SA-FERROVIA possui diferentes tipos de usuários.

### Administrador

O administrador possui acesso às principais funcionalidades de gerenciamento do sistema, podendo:

* Cadastrar usuários;
* Cadastrar trens;
* Cadastrar sensores;
* Editar informações;
* Gerenciar dados;
* Gerar relatórios;
* Acessar informações administrativas.

### Usuário Comum

O usuário comum possui acesso limitado às funcionalidades administrativas, podendo principalmente:

* Visualizar sensores;
* Acompanhar o monitoramento;
* Consultar informações dos trens;
* Visualizar dados disponíveis no sistema.

---

## Relatórios

O sistema possui uma área específica para geração e consulta de relatórios.

Os administradores podem utilizar filtros para selecionar informações de acordo com determinados critérios, facilitando a análise dos dados coletados pelos sensores.

Os relatórios têm como objetivo transformar os dados armazenados no sistema em informações mais organizadas para acompanhamento e análise.

---

## Metodologia

O desenvolvimento do SA-FERROVIA utiliza conceitos de metodologias ágeis, principalmente **Scrum**, buscando organizar as atividades, dividir responsabilidades entre os integrantes e acompanhar a evolução do projeto.

Também são utilizados documentos de pesquisa relacionados ao **CRUD**, **Scrum**, **XAMPP** e identidade visual, disponíveis na pasta `documentos`.

---

## Conclusão

O **SA-FERROVIA** tem como objetivo oferecer uma plataforma organizada para o monitoramento e gerenciamento de informações ferroviárias. Através do sistema, é possível controlar dados relacionados aos trens, sensores, usuários, rotas e relatórios.

A aplicação busca facilitar o acompanhamento das operações ferroviárias, permitindo que os dados coletados sejam armazenados, organizados e apresentados de maneira simples e acessível.

Dessa forma, o projeto reúne conceitos de desenvolvimento web, banco de dados, CRUD, gerenciamento de usuários e metodologias ágeis em uma única aplicação voltada ao monitoramento ferroviário.
